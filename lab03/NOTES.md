# Журнал воркшопа lab03

## Этап 2. Сравнение версий и поиск изменений

### git log, git diff, git show — в чём разница

- `git log` — показывает список коммитов с сообщениями и метаданными.
  Не показывает содержимое изменений.
- `git diff` — показывает разницу между двумя состояниями (коммитами,
  индексом, рабочей папкой). Не показывает метаданные.
- `git show` — показывает один конкретный коммит целиком: автора, дату,
  сообщение и diff этого коммита.

### Что нашли log -S и blame

- `git log -S"def"` искал коммиты, где появлялась или исчезала строка
  с `def`. Ничего не нашёл, потому что в `calc.py` нет функций с `def`.
- `git blame` показал, какая строка файла появилась в каком коммите
  и кем добавлена.
